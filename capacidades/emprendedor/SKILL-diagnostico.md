# Flujo

1. **Cuestionario** (sí/no/no sabe — sin interrogatorio exhaustivo, agrupa en una pasada):

- ¿Tienes negocio en marcha? ¿Inicio de actividades ante el SII? ¿RUT tributario?
- ¿Patente municipal (si corresponde)? ¿Marca registrada?
- ¿Dominio? ¿Correo profesional? ¿Página web? ¿Redes sociales activas?
- ¿Catálogo/carrito? ¿Medios de pago (Transbank/Mercado Pago/transferencias)? ¿WhatsApp de contacto?
- ¿Llevas contabilidad o registros? ¿Conoces tus costos y margen?
- ¿Consigues clientes de forma sistemática o esporádica?
- ¿Automatizas algo (agenda, respuestas, cobros)? ¿Has postulado a fondos públicos?

2. **Nivel de madurez**:

- **Nivel 1 — Sobreviviendo**: actividad económica existe, todo depende de ti, casi nada formalizado ni digital
- **Nivel 3 — Operando**: vendes, tienes presencia digital y procesos básicos, pero pierdes tiempo en tareas repetitivas
- **Nivel 5 — Escalable**: procesos digitalizados, captación sistemática, automatizaciones y datos para decidir

3. **Mapa con ubicación** — muestra las 7 zonas con el emprendedor marcado:

```
FORMALIZACIÓN   PRESENCIA   VENTA   CAPTACIÓN   OPERACIÓN   AUTOMATIZACIÓN   FINANCIAMIENTO
     ●                                                                              
```

4. **Respuesta obligatoria — tres partes, nunca más**:

- `Estás aquí → ● [zona actual + nivel]`
- `Tu siguiente paso → [UNA sola acción concreta, la de mayor desbloqueo]`
- `Todavía NO necesitas → [2-3 cosas que el emprendedor suele sobreestimar a este nivel: CRM empresarial, app propia, Kubernetes...]`

# Reglas

- Un siguiente paso a la vez: el desbloqueo no es una lista de compras
- La zona FORMALIZACIÓN tapa a las demás: sin RUT/inicio de actividades no hay pasarela de pago ni fondos
- "No sabe" cuenta como "no" en el nivel, pero se marca como pregunta a resolver en el siguiente paso
- Al completar un paso, el emprendedor vuelve al cuestionario: el mapa se re-evalúa (círculo virtuoso)
