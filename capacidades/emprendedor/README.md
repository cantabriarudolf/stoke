# CAPACIDAD EMPRENDEDOR — primera línea de defensa

Módulo transportable de STOKE para el emprendedor (especialmente el chileno): orientación, formalización, stack ultra-low-cost y financiamiento público. Conocimiento que nace con el kit — es OFERTA propia de la marca, no dominio de un anfitrión.

## Qué aporta

4 skills prácticas — una línea por tema, cero redundancia, algo de cada uno:

| Skill | Responde | Para quién |
|---|---|---|
| [SKILL-diagnostico.md](SKILL-diagnostico.md) | ¿Dónde estoy? → nivel de madurez + mapa de 7 zonas + siguiente paso único | Todo emprendedor |
| [SKILL-formalizacion.md](SKILL-formalizacion.md) | ¿Qué necesito frente al SII y el municipio? | El que se formaliza |
| [SKILL-rata.md](SKILL-rata.md) | ¿Cuánto construyo sin gastar plata? | El de presupuesto cero |
| [SKILL-fondos.md](SKILL-fondos.md) | ¿Qué fondo público me conviene y qué me falta para postular? | El que necesita financiamiento |

## El mapa de 7 zonas

FORMALIZACIÓN → PRESENCIA → VENTA → CAPTACIÓN → OPERACIÓN → AUTOMATIZACIÓN → FINANCIAMIENTO

El emprendedor no recibe una montaña de herramientas: recibe "estás aquí ●", su siguiente paso, y qué NO necesita todavía.

## Principios

- **STOKE no es el protagonista**: el protagonista es el emprendedor y su mapa
- **Anti-abrumamiento**: nunca más de un siguiente paso a la vez; declarar explícitamente lo que aún NO necesita
- **Rata primero**: agotar lo gratuito/ultra-barato antes de pagar; pagar solo cuando el negocio lo justifica
- **Chile-first con gancho**: los ejemplos son chilenos (SII, Empresa en un Día, fondos.gob.cl, CuentaFan Empresas, Scotiapyme); todo lleva "verifica tu país"
- **Sin inventar**: precios, requisitos y convocatorias cambian — verificar fuente oficial antes de afirmar

## Instalación

```bash
bash install.sh <perfil> [raiz] --capacidad emprendedor
```

Los agentes `@alivio` (orientador) y `@fondos` (financiamiento) vienen incluidos en STOKE y usan estas skills.
