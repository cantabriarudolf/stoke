# La pregunta correcta

No es "cuáles son las mejores herramientas del mercado". Es: **"veamos cuánto puedes construir sin gastar plata"**. Y recién cuando el negocio lo justifica, pagar.

# El stack rata

| Necesidad | Solución ultra-low-cost |
|---|---|
| Empresa | Empresa en un Día (Chile) |
| Firma | Firma electrónica económica (~$1.000 CLP) |
| Dominio | dominio barato (.cl o .com en oferta inicial) |
| Hosting/servidor | Oracle Cloud Always Free ⚠ requiere tarjeta, sin cargos · Vercel/Netlify/Cloudflare Pages (tier free) |
| Web | plantilla + IA |
| Catálogo | la propia web |
| Carrito | solución open source |
| Pagos | Transbank Webpay / Mercado Pago (se paga por venta, no fijo) |
| Contacto | WhatsApp / botón de contacto |
| Agenda | Google Calendar (free) |
| Automatización | n8n (self-host en free tier) |
| Base de datos | Supabase/PostgreSQL (tier free) |
| IA | opencode + modelos free de Zen (cuenta Zen) |
| Código | STOKE + OpenCode |
| CRM | inicialmente una BD simple, NO un CRM empresarial |
| RRSS | contenido generado con IA + programación de publicaciones |
| Prospectos | agentes + automatización |
| Bancarización | separar flujos: cuenta empresa — ej. Chile: CuentaFan Empresas (Banco de Chile) o Scotiapyme gratis (*verifica tu país y condiciones vigentes*) |
| Fondos | agente @fondos + fondos.gob.cl |

# Reglas

- Orden de gratuidad: primero lo 100% gratis (Zen, Vercel, Supabase free), después lo de pago-por-uso (pasarela), lo fijo mensual al final — solo si el negocio lo justifica
- Advertencia obligatoria donde hay trampa: Oracle exige tarjeta "sin cargos" pero la retiene en validación; los tiers free expiran o cambian — verificar vigencia
- Cada fila se entrega con UNA línea de "cómo empezar hoy", no un tutorial
- Si el emprendedor no sabe tecnología: mostrar solo la columna "Necesidad" y ocultar la complejidad — la columna "Solución" es para STOKE, no para él
